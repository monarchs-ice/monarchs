MONARCHS grid variables

List of MONARCHS model grid variables. Generated automatically from the variable catalogue (monarchs.variables). run python scripts/gen_docs.py to regenerate!

Units broadly follow the CF conventions - see https://cfconventions.org/Data/cf-conventions/cf-conventions-1.7/build/ch03.html for details.

Fixed values

column

Long name: Grid column index  ·  Dim: scalar  ·  Units: 1  ·  Default: from input

row

Long name: Grid row index  ·  Dim: scalar  ·  Units: 1  ·  Default: from input

vert_grid

Long name: Firn layer count  ·  Dim: scalar  ·  Units: 1  ·  Default: computed (n_firn)

vert_grid_lake

Long name: Lake layer count  ·  Dim: scalar  ·  Units: 1  ·  Default: computed (n_lake)

vert_grid_lid

Long name: Lid layer count  ·  Dim: scalar  ·  Units: 1  ·  Default: computed (n_lid)

lat

Long name: Latitude  ·  Dim: scalar  ·  Units: degrees_north  ·  Default: nan

lon

Long name: Longitude  ·  Dim: scalar  ·  Units: degrees_east  ·  Default: nan

size_dx

Long name: Cell size, east-west  ·  Dim: scalar  ·  Units: m  ·  Default: 1000.0

size_dy

Long name: Cell size, north-south  ·  Dim: scalar  ·  Units: m  ·  Default: 1000.0

valid_cell

Long name: Cell runs model physics (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: True

Firn

firn_depth

Long name: Firn column total depth  ·  Dim: scalar  ·  Units: m  ·  Default: from input

vertical_profile

Long name: Depth of each firn layer  ·  Dim: firn  ·  Units: m  ·  Default: computed (vertical_profile)

firn_temperature

Long name: Firn column temperature  ·  Dim: firn  ·  Units: K  ·  Default: from input

rho

Long name: Firn density  ·  Dim: firn  ·  Units: kg m-3  ·  Default: from input

Sfrac

Long name: Solid (ice) volume fraction  ·  Dim: firn  ·  Units: 1  ·  Default: computed (sfrac_from_rho)

Lfrac

Long name: Liquid (water) volume fraction  ·  Dim: firn  ·  Units: 1  ·  Default: 0.0

meltflag

Long name: Meltwater present at layer (flag)  ·  Dim: firn  ·  Units: 1  ·  Default: 0.0

saturation

Long name: Layer saturated (flag)  ·  Dim: firn  ·  Units: 1  ·  Default: 0.0

ice_lens

Long name: Ice lens present (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: False

ice_lens_depth

Long name: Layer index of highest ice lens  ·  Dim: scalar  ·  Units: 1  ·  Default: computed (ice_lens_below_column)

Surface

albedo

Long name: Surface albedo  ·  Dim: scalar  ·  Units: 1  ·  Default: 0.0

melt

Long name: Surface melt this step (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: False

exposed_water

Long name: Exposed surface water (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: False

total_melt

Long name: Cumulative melt depth  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

Lake

lake

Long name: Lake present (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: False

lake_depth

Long name: Melt lake depth  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

lake_temperature

Long name: Lake temperature profile  ·  Dim: lake  ·  Units: K  ·  Default: 273.15

Lid

lid

Long name: Frozen lid present (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: False

lid_depth

Long name: Frozen lid depth  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

lid_temperature

Long name: Frozen lid temperature profile  ·  Dim: lid  ·  Units: K  ·  Default: 273.15

v_lid

Long name: Virtual lid present (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: False

v_lid_depth

Long name: Virtual lid depth  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

virtual_lid_temperature

Long name: Virtual lid temperature  ·  Dim: scalar  ·  Units: K  ·  Default: 273.15

has_had_lid

Long name: Lid present this cycle (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: False

lid_sfc_melt

Long name: Tracked lid surface melt  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

lid_snow_depth

Long name: Snow depth on the lid  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

snow_on_lid

Long name: Snow-on-lid state (0/1/2)  ·  Dim: scalar  ·  Units: 1  ·  Default: 0

Lateral

water

Long name: Liquid water depth per layer (lateral flow)  ·  Dim: firn  ·  Units: m  ·  Default: 0.0

water_level

Long name: Water-table height for lateral flow  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

water_direction

Long name: Lateral outflow direction (0=NW..7=W)  ·  Dim: directions  ·  Units: 1  ·  Default: 0

Diagnostic

firn_boundary_change

Long name: Firn boundary change this day  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

lake_boundary_change

Long name: Lake boundary change this day  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

lid_boundary_change

Long name: Lid boundary change this day  ·  Dim: scalar  ·  Units: m  ·  Default: 0.0

Counter

melt_hours

Long name: Cumulative surface-melt hours  ·  Dim: scalar  ·  Units: h  ·  Default: 0

lid_melt_count

Long name: Lid melt-step counter  ·  Dim: scalar  ·  Units: 1  ·  Default: 0

lake_refreeze_counter

Long name: Lake refreeze counter  ·  Dim: scalar  ·  Units: 1  ·  Default: 0

exposed_water_refreeze_counter

Long name: Exposed-water refreeze counter  ·  Dim: scalar  ·  Units: 1  ·  Default: 0

t_step

Long name: Timestep within the current day  ·  Dim: scalar  ·  Units: 1  ·  Default: 0

day

Long name: Model day  ·  Dim: scalar  ·  Units: 1  ·  Default: 0

visit_count

Long name: Times this cell has been visited  ·  Dim: scalar  ·  Units: 1  ·  Default: 0

Internal

reset_combine

Long name: Lid/firn just combined (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: False

Flag indicating whether a lid/lake/firn system has reached a trigger that combines everything back into a single firn column.

error_flag

Long name: Cell hit an error state (flag)  ·  Dim: scalar  ·  Units: 1  ·  Default: False
