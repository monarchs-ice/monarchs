monarchs.variables.definitions

Definitions of what a variable is in terms of what the model needs. Each variable needs to have some specific fields in order for the model to use them, e.g. their dtype, shape and name.

We also define a class used to handle some edge cases - e.g. variables that are defined based on other model variables, e.g. Sfrac which is defined by the density.
