monarchs.config

MONARCHS run-settings schema.

Files:

catalogue.py - contains all model_setup variable definitions. rules.py - rules that apply to settings or combinations of settings definitions.py - computed_defaults.py - calculate default values for settings that are

dependent on other settings

apply.py - apply the config at runtime, run validation, fill default values docs.py - converts the catalogue to documentation
