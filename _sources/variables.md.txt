# MONARCHS grid variables

List of MONARCHS model grid variables. Generated automatically from the variable catalogue (`monarchs.variables`).  run `python scripts/gen_docs.py` to regenerate!

Units broadly follow the CF conventions - see https://cfconventions.org/Data/cf-conventions/cf-conventions-1.7/build/ch03.html for details.

## Fixed values

### `column`

**Long name:** Grid column index &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** 1 &nbsp;·&nbsp; **Default:** from input

### `row`

**Long name:** Grid row index &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** 1 &nbsp;·&nbsp; **Default:** from input

### `vert_grid`

**Long name:** Firn layer count &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** 1 &nbsp;·&nbsp; **Default:** computed (`n_firn`)

### `vert_grid_lake`

**Long name:** Lake layer count &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** 1 &nbsp;·&nbsp; **Default:** computed (`n_lake`)

### `vert_grid_lid`

**Long name:** Lid layer count &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** 1 &nbsp;·&nbsp; **Default:** computed (`n_lid`)

### `lat`

**Long name:** Latitude &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** degrees_north &nbsp;·&nbsp; **Default:** `nan`

### `lon`

**Long name:** Longitude &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** degrees_east &nbsp;·&nbsp; **Default:** `nan`

### `size_dx`

**Long name:** Cell size, east-west &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** m &nbsp;·&nbsp; **Default:** `1000.0`

### `size_dy`

**Long name:** Cell size, north-south &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** m &nbsp;·&nbsp; **Default:** `1000.0`

### `valid_cell`

**Long name:** Cell runs model physics (flag) &nbsp;·&nbsp; **Dim:** scalar &nbsp;·&nbsp; **Units:** 1 &nbsp;·&nbsp; **Default:** `True`
