MONARCHS met forcing variables

Fields of the met data grid (one record per timestep per cell), from the met catalogue (monarchs.met_data.catalogue). The ERA5 name is the short name(s) the field is read from when using ERA5 input data.

snowfall

Long name: Snowfall  ·  Units: m  ·  ERA5 name: sf

snow_dens

Long name: Snow density  ·  Units: kg m-3  ·  ERA5 name: rsn

temperature

Long name: Surface air temperature  ·  Units: K  ·  ERA5 name: t2m

wind

Long name: Wind speed  ·  Units: m s-1  ·  ERA5 name: u10, v10

surf_pressure

Long name: Surface air pressure  ·  Units: hPa  ·  ERA5 name: sp

dew_point_temperature

Long name: Dew-point temperature  ·  Units: K  ·  ERA5 name: d2m

LW_down

Long name: Downwelling longwave radiation  ·  Units: W m-2  ·  ERA5 name: strd

SW_down

Long name: Downwelling shortwave radiation  ·  Units: W m-2  ·  ERA5 name: ssrd

lat

Long name: Latitude  ·  Units: degrees_north  ·  ERA5 name: latitude

lon

Long name: Longitude  ·  Units: degrees_east  ·  ERA5 name: longitude
